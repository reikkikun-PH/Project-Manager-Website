WHY THIS EXISTS

host.py opens a Cloudflare quick tunnel every run and Cloudflare hands it a random *.trycloudflare.com address. You can't stop that — but you can stop sharing it.

Share this page's address instead (username.github.io/repo/). A small publisher script (publish-live.py in the Server folder) copies each new tunnel URL into live.json next to this file, so this page always forwards to the current session. Allow ~30–60s after launching for GitHub Pages to rebuild.

Want a truly instant static address with no sync step? That's a Cloudflare named tunnel + your own domain (cloudflared tunnel login → cloudflared tunnel create pm → route pm.yourdomain.com). Nothing random, no GitHub needed. See README.md in this folder.
